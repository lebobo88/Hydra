# Documentation

Describe Claude Code features as host-interface capabilities and identify the
Hydra component that remains authoritative. Do not imply that native memory,
Agent Teams, dynamic workflows, generic permissions, or prompt guardrails
replace Hydra's typed state, governance, or execution protocol.

When documenting external behavior, cite the authoritative source and mark
experimental Claude Code features as experimental.
